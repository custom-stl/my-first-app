# さんすうノート

小学1〜2年生向けの算数ドリルアプリ。`index.html` 一枚で動きます（ビルド不要・オフライン可）。

```
# そのままブラウザで開くだけ
open index.html          # macOS
xdg-open index.html      # Linux

# ローカルサーバーで見る場合
npx http-server . -p 8080
```

## ログインなしで使う

サーバーもアカウントも使わない静的なページなので、**認証なしで動きます**（通信するのは Google Fonts の読み込みだけで、それが遮断されても端末の書体で問題なく動きます）。方法は3つあります。

### 1. GitHub Pages で公開する

`.github/workflows/pages.yml` を用意してあり、`main` への push で自動デプロイします。公開先は `https://<ユーザー名>.github.io/my-first-app/` です。

**ただし、このリポジトリは現在 private です。** GitHub Pages を private リポジトリで使うには GitHub Pro などの有料プランが必要で、無料プランでは公開リポジトリからしか公開できません（2026年9月時点でデプロイは `Create Pages site failed. Resource not accessible by integration` で失敗します）。

- **リポジトリを public にする場合**: public にして `main` に push すれば、`configure-pages` の `enablement: true` により Pages が自動で有効になります。有効にならない場合だけ、一度 **Settings → Pages → Source** を **「GitHub Actions」** にしてください。ソースコードも公開される点にご注意ください。
- **private のままにしたい場合**: 下の方法2・3を使うか、GitHub Pro 等に加入してください。

URLを開くだけで使えます。スマホ・タブレットのブラウザメニューから**「ホーム画面に追加」**すると、アイコン付きでアプリのように全画面で起動します。

> 公開URLはリンクを知っている人なら誰でも開けます。このアプリは入力を外部に送信しないので個人情報が漏れることはありませんが、URL自体は公開になります。

### 2. 端末に保存してオフラインで使う

`index.html` を端末に保存してブラウザで開くだけです。ネット接続も不要で、機内モードでも動きます。アイコンも使いたい場合は `index.html` / `manifest.webmanifest` / `icon.svg` / `icon-192.png` / `icon-512.png` / `icon-180.png` を同じフォルダに置いてください。

### 3. 無料の静的ホスティングに置く（private のままでOK）

フォルダごと [Netlify Drop](https://app.netlify.com/drop) にドラッグするだけで、ログイン不要の公開URLがもらえます（ビルド不要、リポジトリを公開する必要もありません）。Cloudflare Pages や Vercel でも同様です。

記録は端末のブラウザに保存される（`localStorage`）ため、公開URLで使っても**他の人に自分の記録は見えません**。逆に、同じ端末の同じブラウザでないと記録は引き継がれません。

## 問題の種類

| メニュー | 内容 |
| --- | --- |
| ひっさん | たし算・ひき算を筆算の形で出題（最大4桁） |
| ぶんしょうだい | 買い物・バス・折り紙など、暮らしに合わせた文章問題（17種類の題材）。ケロちゃん・コロちゃんがよく登場します |
| とけい | アナログ時計の読み取り、時計えらび（4択）、「〇分あと／まえ」 |
| ミックス | 上の3種類をまとめて10問 |

1セット10問。レベルは3段階で、メニューをまたいで共通です。

| レベル | ひっさん | ぶんしょうだい | とけい |
| --- | --- | --- | --- |
| やさしい | 2桁 | 20まで（お金は10倍） | 5分きざみ・4択 |
| ふつう | 3桁（3桁＋2桁を含む） | 100まで | 1分きざみ・4択 |
| むずかしい | 4桁（4桁＋3桁を含む） | 1000まで | 目盛りの数字なし・何分あと／まえ |

ひき算の答えがマイナスになる問題、文章問題でレベルの範囲を超える答えは出題されません。

## きろく（日単位の実績）

10問終わるごとに、その1セットがブラウザに保存されます（日付・時刻・メニュー・レベル・点数・10問ぶんの問題と答え）。ホーム画面の「きろくを みる」から確認できます。

- **今日の問題数・連続日数・通算の正解数**を上部に表示
- **直近2週間の棒グラフ**（1日1本、正解＝朱色／まちがい＝藍色の積み上げ）。バーをタップ（PCはマウスを乗せる）すると、その日の内容が下の行に出ます
- **日ごとの記録**：日付・その日の正解数と、セットごとの行。行を開くと**10問すべての問題・正しい答え・子どもが書いた答え**を後から確認できます
- 「きろくを ぜんぶ けす」で消去（2段階で確認します）

保存先はブラウザの `localStorage`（キー `sn-log-v1`、最新300セットまで）です。**端末・ブラウザごとの保存**なので、別の端末とは共有されません。同じ端末で同じブラウザを使えば、アプリを閉じても残ります。

## みんなの きろく（サーバーに のこして 人ごとに 集計）

記録を端末の中だけでなく**サーバー側にも保存**し、**複数名を人ごとに集計**できます。サーバーを用意しなくてもアプリは今までどおり動きます（端末内の記録だけになります）。

### 人の区別（ログインなし）

ホーム画面の「**だれが やる？**」で名前（ニックネーム）を選びます。「＋ ひとを ふやす」で最大8人まで登録でき、記録にはそのときの名前が付きます。

同じ人かどうかは名前で判定するので、**別の端末で同じ名前を選べばサーバー側で1人ぶんにまとまります**（名前を変えると別の人になります）。端末から人を消すのは「きろく」画面の「この たんまつの 人」からできます。

### 送信のしかた

1. `server/README.md` の手順でサーバーを用意する（Cloudflare Workers の無料枠、または自分のPC）
2. アプリの「きろく」画面 → **サーバー（みんなの きろく）**に URL と あいことばを入れて「ほぞんして ためす」

10問終わるごとに自動で送信します。電波がないときや設定前の記録は端末に溜まり、次に開いたときやボタンで送れます（送信済みの記録は二重に登録されません）。

### 見かた

「きろく」画面の「**みんなの きろくを みる**」を押すと、人ごとのカードが並びます。今日の正解数・連続日数・通算、直近2週間の棒グラフが人ごとに出ます（棒の縦軸は全員で揃えているので、そのまま見比べられます）。

サーバー側では SQL で自由に集計できます（`server/README.md` を参照）。

> ログインのしくみは入れていないため、**URLとあいことばを知っている人は書き込めます**。家庭で使う前提の作りです。送るのはニックネーム・日付・点数・問題と答えだけで、本名や連絡先は使わないでください。

## 使い方

- 答えは画面の数字ボタンで入力します（パソコンでは数字キー / Backspace / Esc / Enter、時計の「じ・ふん」欄は ← → で移動）。
- 正解すると答えに**花まる**がつき、自動で次の問題へ。ほめ言葉は毎回変わり、3問続けて正解すると「3もん れんぞく せいかい！」と出ます。まちがえたときは正しい答えを見せてから次に進みます。
- 10問終わると、はんこ・星と**ほめるコメント**、そして「**できた もんだい**」の一覧（花まる付き）が出ます。
- ほめるコメントは、点数に応じた言葉・種類ごとの正解数（「4けたの ひっさんが 7もん せいかい！」）・最長の連続正解・自己最高記録の更新（「まえより 3もん おおく できたよ！」）から作られます。0問のときも「10もん ぜんぶ ちょうせん したね！」とねぎらう作りで、けなす言葉は出しません。
- まちがえた問題は、ほめたあとに「みなおし」として正しい答えとともに並びます。
- **「こえ オン／オフ」**でケロちゃん・コロちゃんの声を切り替え。「おと オン／オフ」は効果音です。レベル・音・声の設定と記録はブラウザに保存されます。
- 結果画面の「きろく」ボタンからも、過去の記録を見られます。

## キャラクター

ケロちゃんとコロちゃん（カエルの2匹）が、ホーム画面・答え合わせ・結果画面に登場し、文章問題の登場人物にもなります。ほめ言葉にも顔を出します（「ケロちゃんも びっくり！」など）。

**絵はこのアプリのために描いたオリジナルのSVG**です（コーワの公式キャラクターの絵柄は使っていません）。名前はお子さんが親しんでいる呼び名として使っているため、家庭での利用を前提としています。配布・公開する場合は名前を変えてください。`frogSVG()` の色とリボンを変えるだけで別のキャラクターに差し替えられます。

## ケロちゃん・コロちゃんの こえ

答え合わせのたびに、画面に出ているカエルが声で教えてくれます。

- 正解 → 「あたり！ すごい！」「せいかい！ やったね！」など（ほめ言葉は毎回変わります）
- まちがい → 「おしい！ こたえは 46 だよ」と**正しい答えを読み上げます**（時計は「8じ 15ふん」のように区切って読みます）
- 10問終わったときも、結果のひとことを読み上げます
- ケロちゃんは少しゆっくり低め、コロちゃんは高めで元気に（端末に日本語の声が2種類あれば別々の声を使います）

しくみは**端末に入っている日本語の音声読み上げ**（Web Speech API）です。音声ファイルは同梱しておらず、通信も不要です。

| 端末 | 声 |
| --- | --- |
| iPhone / iPad / Mac | 最初から日本語の声が入っています（Kyoko など） |
| Android | 日本語の音声サービスが入っていれば使えます |
| Windows / PC のブラウザ | 日本語の音声が入っていないことがあります。その場合は声は出ず、ボタンが「こえ なし」になります（効果音だけになります） |

声を止めたいときは「こえ オフ」を押してください。

## つくり

- 依存ライブラリなし。HTML + CSS + バニラJSの1ファイル構成（アイコン・マニフェスト・`config.js`・`server/` を除く）。
- サーバーのURLとあいことばは、アプリの画面から入れるか `config.js` に書けます。API本体（`server/api.mjs`）は Cloudflare Workers 版とローカル版で共通です。
- `manifest.webmanifest` とアイコンを同梱し、「ホーム画面に追加」で全画面のアプリとして起動します。
- キャラクターと花まる、時計はすべて SVG をコードで生成（画像ファイルなし）。
- 時計は学習用時計を SVG で生成（外側の輪に「分」の数字、短針＝朱色、長針＝藍色）。
- 書体は Google Fonts（Kiwi Maru / Zen Kaku Gothic New / M PLUS Rounded 1c）。読み込めない環境でも端末の書体で崩れずに表示されます。
- 文章は**わかち書き**にし、`word-break: keep-all` で語の途中（「ケロちゃ／んは」など）で行が折り返さないようにしています。
- 棒グラフの2色は同梱の検証スクリプト（dataviz skill の `validate_palette.js`）で、色覚特性・コントラストを確認して選んでいます（ライト `#e4523f`／`#2b6ca3`、ダーク `#e8603f`／`#3f8fd0`）。
- ライトテーマ／ダークテーマの両方に対応。スマートフォン幅（〜400px）でも横スクロールしません。
