# べんきょうノート

小学1〜2年生向けの**算数・英語・漢字・タイピング**のドリルアプリ。`index.html` 一枚で動きます（ビルド不要・オフライン可）。

トップ画面から **さんすう / えいご / かんじ / タイピング / きろく** に進みます。レベル・キャラクター・記録・録音した声は4つのアプリで共通です。

```
# そのままブラウザで開くだけ
open index.html          # macOS
xdg-open index.html      # Linux

# ローカルサーバーで見る場合
npx http-server . -p 8080
```

## 公開先

**https://sparkly-nougat-5bb9ae.netlify.app/** （Netlify Drop）

更新するときは、配布用の一式（`index.html` / `config.js` / `manifest.webmanifest` / `icon.svg` / `icon-180.png` / `icon-192.png` / `icon-512.png`）をフォルダにまとめ、Netlify のサイトの **Deploys** にドラッグ＆ドロップします（URLは変わりません）。

GitHubリポジトリとNetlifyを連携すると、`main` への push だけで自動更新できます（Netlifyはprivateリポジトリにも接続できるので、公開する必要はありません）。手順は Netlify の **Site configuration → Build & deploy → Continuous deployment → Link repository** です。

## ログインなしで使う

サーバーもアカウントも使わない静的なページなので、**認証なしで動きます**（通信するのは Google Fonts の読み込みだけで、それが遮断されても端末の書体で問題なく動きます）。方法は3つあります。

### 1. GitHub Pages で公開する

`.github/workflows/pages.yml` を用意してあり、`main` への push で自動デプロイします。公開先は `https://<ユーザー名>.github.io/my-first-app/` です。

**ただし、このリポジトリは現在 private です。** GitHub Pages を private リポジトリで使うには GitHub Pro などの有料プランが必要で、無料プランでは公開リポジトリからしか公開できません（2026年9月時点でデプロイは `Create Pages site failed. Resource not accessible by integration` で失敗します）。

- **リポジトリを public にする場合**: public にして `main` に push すれば、`configure-pages` の `enablement: true` により Pages が自動で有効になります。有効にならない場合だけ、一度 **Settings → Pages → Source** を **「GitHub Actions」** にしてください。ソースコードも公開される点にご注意ください。
- **private のままにしたい場合**: 下の方法2・3を使うか、GitHub Pro 等に加入してください。

URLを開くだけで使えます。スマホ・タブレットのブラウザメニューから**「ホーム画面に追加」**すると、アイコン付きでアプリのように全画面で起動します。

> 公開URLはリンクを知っている人なら誰でも開けます。このアプリは入力を外部に送信しないので個人情報が漏れることはありませんが、URL自体は公開になります。

### 2. 端末に保存してオフラインで使う

`index.html` を端末に保存してブラウザで開くだけです。ネット接続も不要で、機内モードでも動きます。アイコンも使いたい場合は `index.html` / `manifest.webmanifest` / `icon.svg` / `icon-192.png` / `icon-512.png` / `icon-180.png` を同じフォルダに置いてください。

### 3. 無料の静的ホスティングに置く（private のままでOK）

フォルダごと [Netlify Drop](https://app.netlify.com/drop) にドラッグするだけで、ログイン不要の公開URLがもらえます（ビルド不要、リポジトリを公開する必要もありません）。Cloudflare Pages や Vercel でも同様です。

記録は端末のブラウザに保存される（`localStorage`）ため、公開URLで使っても**他の人に自分の記録は見えません**。逆に、同じ端末の同じブラウザでないと記録は引き継がれません。

## 問題の種類

### さんすう

| メニュー | 内容 |
| --- | --- |
| ひっさん | たし算・ひき算を筆算の形で出題（最大4桁） |
| ぶんしょうだい | 買い物・バス・折り紙など、暮らしに合わせた文章問題（17種類の題材）。ケロちゃん・コロちゃんがよく登場します |
| とけい | アナログ時計の読み取り、時計えらび（4択）、「〇分あと／まえ」 |
| ミックス | 上の3種類をまとめて10問 |

### えいご

すべて4択です。答えは画面をタップ（パソコンでは 1〜4 キー、スペースでもう一度聞く）。

| メニュー | 内容 |
| --- | --- |
| ききとり | 英語を聞いて、合う絵を選ぶ |
| えいたんご | 絵を見て、英語のつづりを選ぶ |
| あいさつ | 英語のいいかたの意味を選ぶ（33種類） |
| アルファベット | 聞こえた文字・大文字小文字・並び順 |
| えいご ぜんぶ | 上の4種類をまとめて10問 |

単語は194語（どうぶつ・くだもの・いろ・からだ・みのまわり・かず）。端末に英語の声（Web Speech API）があれば読み上げ、なければカタカナの読みが出るので、そのまま解けます。

### かんじ

主役は**マス**です。十字リーダーの入った漢字練習帳のマスに、うすいお手本と**画の番号**が出るので、**1画ずつ書き順どおりになぞります**。

| メニュー | 内容 |
| --- | --- |
| なぞりがき | お手本を1画ずつなぞる。書き順・向き・画数で判定 |
| よみ | 漢字を見て読みかたを選ぶ |
| かきとり | 読みと意味を見て漢字を選ぶ |
| かんじ ぜんぶ | 3種類まとめて10問 |

漢字は**1年生の80字ぜんぶ**と、2年生からよく使うものを収録。よみ・かきとりのレベルは やさしい（1年生）／ふつう（2年生）／むずかしい（**形の似た漢字から選ぶ**）。

なぞりがきは**1年生80字ぶんの、1画ずつの線データ**を持っています（書き順の順に並んだSVGの道すじ）。指を離した瞬間にその画だけを採点し、**書き始めの位置**と**線の形**（線を10点に分けて、書いた順に比べる）の2つを見ます。順番に比べるので、**書き順が違う・逆向きに引いた・画数が足りない**ものは通りません。ぬりつぶしても通りません。

いま引く画の番号は**紫**、書けた画は**うすいグレー**、なぞれなかった画は**お手本ごと朱色**になります（先生の赤ペンと同じ）。「かきじゅん」を押すとお手本が1画ずつ引かれるので、迷ったらそれを見てから書けます。手ぶれは通る加減にしてあります。

レベルは画数で分けます（やさしい＝4画まで／ふつう＝5〜6画／むずかしい＝7画以上）。2年生の漢字は**よみ・かきとり**には出ますが、線データがないのでなぞりがきには出ません。

### タイピング

画面のキーボードで「つぎに押すキー」と「どの指で押すか」を色で教えます。ホームポジション（F・J）から始めて、だんだん広げます。

| メニュー | 内容 |
| --- | --- |
| もじ | アルファベットを1つずつ |
| たんご | 英単語（意味つき） |
| ローマじ | ひらがなをローマ字で |
| すうじ | 数字キーに慣れる |

やりかたは2つ。**れんしゅう**（10問・時間無制限）と**ゲーム**（60秒で何問）。連続正解でボーナス、ミスなしでパーフェクトボーナス。通算点で「たまご → おたまじゃくし → あしが でた → こガエル → カエルはかせ」と育ち、メダルが8種類あります。まちがえたキーは結果画面に「にがてなキー」として指つきで出ます。

### レベル

1セット10問。レベルは3段階で、さんすう・えいごをまたいで共通です。

| レベル | ひっさん | ぶんしょうだい | とけい | えいご | かんじ（よみ・かきとり） | かんじ（なぞりがき） |
| --- | --- | --- | --- | --- | --- | --- |
| やさしい | 2桁 | 20まで（お金は10倍） | 5分きざみ・4択 | よく使う語 | 1年生の漢字 | 4画まで |
| ふつう | 3桁（3桁＋2桁を含む） | 100まで | 1分きざみ・4択 | 語がふえる | 2年生の漢字 | 5〜6画 |
| むずかしい | 4桁（4桁＋3桁を含む） | 1000まで | 目盛りの数字なし・何分あと／まえ | つづり・形の似たものから | 形の似た漢字から選ぶ | 7画以上 |

ひき算の答えがマイナスになる問題、文章問題でレベルの範囲を超える答えは出題されません。

## きろく（日単位の実績・アプリごと）

記録は**人ごと**に分かれ、さらに **ぜんぶ / さんすう / えいご / かんじ / タイピング** で切り替えて見られます（2つ以上のアプリをやった人にだけ出ます）。タイピングは「うてた問題数 / ミスなしで打てた数」で数え、スコアと正確さは1セットを開くと出ます。



10問終わるごとに、その1セットがブラウザに保存されます（日付・時刻・メニュー・レベル・点数・10問ぶんの問題と答え）。ホーム画面の「きろくを みる」から確認できます。

- **今日の問題数・連続日数・通算の正解数**を上部に表示
- **直近2週間の棒グラフ**（1日1本、正解＝朱色／まちがい＝藍色の積み上げ）。バーをタップ（PCはマウスを乗せる）すると、その日の内容が下の行に出ます
- **日ごとの記録**：日付・その日の正解数と、セットごとの行。行を開くと**10問すべての問題・正しい答え・子どもが書いた答え**を後から確認できます
- 「きろくを ぜんぶ けす」で消去（2段階で確認します）

保存先はブラウザの `localStorage`（キー `sn-log-v1`、最新300セットまで）です。**端末・ブラウザごとの保存**なので、別の端末とは共有されません。同じ端末で同じブラウザを使えば、アプリを閉じても残ります。

## どの端末からやっても 記録をまとめる

`server/` を立てて、きろく画面の「サーバー」にURLを入れると、**スマホ・タブレット・パソコンのどれでやった分も1つにまとまります**。

- 同じ名前を選べば同じ人として集まります（`player_id` は名前から決まります）
- 送信は自動。電波がなくても端末に貯めて、次に開いたときに送ります
- きろく画面を開くと、ほかの端末でやった分を取りに行って、この端末にも取り込みます
- サーバーを立てない場合、アプリはそのまま動きますが**記録はやった端末の中だけ**に残ります

立てかたは [`server/README.md`](server/README.md)（Cloudflare Workers の無料枠か、手元のPCで `node server/dev-server.mjs`）。

## みんなの きろく（サーバーに のこして 人ごとに 集計）

記録を端末の中だけでなく**サーバー側にも保存**し、**複数名を人ごとに集計**できます。サーバーを用意しなくてもアプリは今までどおり動きます（端末内の記録だけになります）。

### 人の区別（ログインなし）

ホーム画面の「**だれが やる？**」で名前（ニックネーム）を選びます。「＋ ひとを ふやす」で最大8人まで登録でき、記録にはそのときの名前が付きます。

同じ人かどうかは名前で判定するので、**別の端末で同じ名前を選べばサーバー側で1人ぶんにまとまります**（名前を変えると別の人になります）。端末から人を消すのは「きろく」画面の「この たんまつの 人」からできます。

### 送信のしかた

1. `server/README.md` の手順でサーバーを用意する（Cloudflare Workers の無料枠、または自分のPC）
2. アプリの「きろく」画面 → **サーバー（みんなの きろく）**に URL と あいことばを入れて「ほぞんして ためす」

10問終わるごとに自動で送信します。電波がないときや設定前の記録は端末に溜まり、次に開いたときやボタンで送れます（送信済みの記録は二重に登録されません）。

### 見かた（個別に確認する）

**サーバーがある場合**：「きろく」画面の「**みんなの きろくを みる**」で人ごとのカードが並びます（今日の正解数・連続日数・通算と、直近2週間の棒グラフ。棒の縦軸は全員で揃えているのでそのまま見比べられます）。

カードの「**〇〇の きろくを くわしく みる**」を押すと、**その子だけの詳しい記録**が出ます。

- その子の今日・連続日数・通算と、直近2週間の棒グラフ
- **しゅるいべつの せいかい**（ひっさん／ぶんしょうだい／とけいごとの正解率）。苦手な種類がひと目で分かります
- **日ごとの記録**。セットの行を開くと10問すべての問題・正しい答え・その子が書いた答えまで確認できます（どの端末で解いたものでも見られます）

**サーバーがない場合**：「みんなの きろくを みる」は**サーバーがなくても使えます**。その端末に記録がある人がカードで並び、「くわしく みる」で日ごと・1問ごとまで確認できます（表示されるのはその端末の分だけです）。サーバーを設定すると、他の端末の分もまとまります。

サーバーにつながらないときも、理由を出したうえで**その端末の分を表示**します（真っ白にはなりません）。

| 画面のメッセージ | 意味 |
| --- | --- |
| サーバーは せっていされて いません | まだ設定していない状態。端末内の記録だけ表示します |
| この ページは https なので、http:// の サーバーには つなげません | ページがhttpsだと、http://のサーバーへの通信はブラウザが遮断します。`https://` のアドレスにしてください |
| サーバー（…）に つながりません | URLの誤り、サーバーが停止、またはCORS（`ALLOW_ORIGIN`）の設定を確認してください |
| あいことばが ちがいます | 「きろく」画面のサーバー欄で確認してください |

また、同じ端末を複数の子で使っているときは、「きろく」画面の上に**名前のボタン**が出ます。押すと、その子の記録に切り替わります。

サーバー側では SQL で自由に集計もできます（`server/README.md` を参照）。

> ログインのしくみは入れていないため、**URLとあいことばを知っている人は書き込めます**。家庭で使う前提の作りです。送るのはニックネーム・日付・点数・問題と答えだけで、本名や連絡先は使わないでください。

## 使い方

- トップ画面で名前を選び、**さんすう**か**えいご**に進みます。「きろくを みる」も同じトップからです。
- さんすうの答えは画面の数字ボタンで入力します（パソコンでは数字キー / Backspace / Esc / Enter、時計の「じ・ふん」欄は ← → で移動）。
- えいごと時計えらびは4択のタップです（パソコンでは 1〜4 キー、スペースで英語をもう一度聞く、Enter で次へ）。答え合わせのあと、正解に ○、選んだまちがいに ✕ が付きます。
- **1問ごとに2匹そろって反応します。ケロちゃんが判定してほめ、コロちゃんがフォローします。**
  - 正解 → ケロ「せいかい！ すごい！」＋ コロ「その ちょうしコロー！」（3問続けば「3もん れんぞくコロー！」）
  - まちがい → ケロ「おしい！ こたえは 46」＋ コロが**まちがいの種類に応じたヒント**
- 正解すると答えに**花まる**がつき、自動で次の問題へ。まちがえたときは自分で「つぎの もんだい」を押します。
- 10問終わると、はんこ・星と**ほめるコメント**、そして「**できた もんだい**」の一覧（花まる付き）が出ます。
- ほめるコメントは、点数に応じた言葉・種類ごとの正解数（「4けたの ひっさんが 7もん せいかい！」）・最長の連続正解・自己最高記録の更新（「まえより 3もん おおく できたよ！」）から作られます。0問のときも「10もん ぜんぶ ちょうせん したね！」とねぎらう作りで、けなす言葉は出しません。
- まちがえた問題は、ほめたあとに「みなおし」として正しい答えとともに並びます。
- **「こえ オン／オフ」**でケロちゃん・コロちゃんの声（アニメごえ・ことば）を切り替え。「おと オン／オフ」は効果音です（こえをオフにすると効果音で知らせます）。レベル・音・声の設定と記録はブラウザに保存されます。
- 結果画面の「きろく」ボタンからも、過去の記録を見られます。

## キャラクター

ケロちゃんとコロちゃん（カエルの2匹）が、トップ画面・答え合わせ・結果画面に登場し、文章問題の登場人物にもなります。えいごでは問題を出す側にもまわります（「ケロちゃんが いうよ。」）。ほめ言葉にも顔を出します（「ケロちゃんも びっくり！」など）。

**絵はこのアプリのために描いたオリジナルのSVG**です（コーワの公式キャラクターの絵柄は使っていません）。名前はお子さんが親しんでいる呼び名として使っているため、家庭での利用を前提としています。配布・公開する場合は名前を変えてください。`frogSVG()` の色とリボンを変えるだけで別のキャラクターに差し替えられます。

## ケロちゃん・コロちゃんの こえ

答え合わせのたびに、画面に出ているカエルが声で教えてくれます。**さんすうでも えいごでも同じ声**です（録音した声もそのまま両方で使われます）。

えいごのときは、ケロちゃんの声 → **英語の読み上げ** → コロちゃんの声 の順に、重ならないように鳴らします（まちがえたときは英語を2回）。英語の声は「きろく」画面の「えいごの こえ」で選べます。

**名前を呼びます。** 「だれが やる？」で選んでいる名前を頭につけて「**はると、やったねケロー！**」と声をかけます（結果画面のふきだしにも名前が出ます）。

**2匹の声は重なりません。** ケロちゃんが**話し終わってから**コロちゃんが始まります（アニメごえ・ことば・録音した声のどれでも同じで、混ざって聞き取れなくなることはありません）。正解のときに自動で次の問題へ進むのも、**2匹が話し終わるのを待ってから**です。「つぎの もんだい」を押したり途中でやめたりすると、残っている声はその場で止まります。

- 正解 → ケロ「やったねケロー！」→ コロ「その ちょうしコロー！」（語尾が「〜ケロ」「〜コロ」に）
- まちがい → ケロが**正しい答えを読み上げ**（時計は「8じ 15ふん」と区切って読みます）→ コロがヒントを読み上げ
- 10問終わったときも、名前を呼んで結果のひとことを読み上げます

### まちがいのフォロー

コロちゃんのヒントは、**何をまちがえたか**を見て変わります。

| まちがい | コロちゃんのひとこと |
| --- | --- |
| たし算で10・100・1000ずれた | 「くりあがりを 1つ わすれて いるかもコロ」 |
| ひき算で10・100・1000ずれた | 「くりさがりを わすれて いるかもコロ」 |
| 答えの桁数が合わない | 「けたを そろえて かくと まちがえにくいコロ」 |
| 1〜2しか違わない | 「あと ちょっと！ いちのくらいから もう いちどコロ」 |
| 文章問題（ひき算の問題） | 「「のこり」や「ちがい」は ひきざんだコロ」 |
| 文章問題（たし算の問題） | 「「あわせて」「ぜんぶで」は たしざんだコロ」 |
| 時計で長針と短針を取りちがえた | 「みじかい はりが「じ」、ながい はりが「ふん」だコロ」 |
| 時計で「時」だけちがう | 「みじかい はりが つぎの すうじに いく まえは、まだ まえの「じ」だコロ」 |
| 時計で「分」だけちがう | 「ながい はりは すうじ 1つで 5ふん、1めもりで 1ふんだコロ」 |
| 「〇分あと」の問題 | 「ながい はりを 〇めもり すすめて みようコロ」 |

### じぶんの こえを つかう（ろくおん）

**おうちの人の声をそのままケロちゃん・コロちゃんの声にできます。**「きろく」画面の「**じぶんの こえを つかう（ろくおん）**」から、アプリの中で録音します（アプリ以外の準備は不要です）。

1. 「● ろくおん」を押して、**3秒以内**で声を入れる（自分で止めるか、3秒で自動的に止まります）
2. 「▶ きいて みる」で確認。撮り直しは「● ろくおん」をもう一度
3. 「**こえの たかさ（はやさ）**」のスライダーで、キャラクターらしい高さに調整（1.0〜1.8倍。**再生を速めることで声が高くなる**しくみです。大人の声でも1.3〜1.5倍でカエルらしくなります）

録音する場面は4つです。全部そろえなくても、**録音した分だけ**使われます（残りはアニメごえのまま）。

| らん | 入れる声の例 |
| --- | --- |
| ケロ・ほめる | 「せいかい！ やったね！」 |
| ケロ・しらせる | 「おしい！」 |
| コロ・ほめる | 「その ちょうし！」 |
| コロ・フォロー | 「つぎは できるよ！」 |

- コロちゃんは同じ録音でも**1.12倍高く**再生されるので、2匹の声が分かれます
- まちがえたときの**答えの読み上げ**（「こたえは 46 だよー」）は、録音ではなく端末の読み上げが続けて担当します
- 録音は**その端末のブラウザの中だけ**に保存されます（`localStorage`。どこにも送信しません）。「けす」で削除できます
#### 録音した声が消えたとき

録音はブラウザのストレージ（`localStorage`）に入っています。**アプリが消すことはありません**が、次の場合にブラウザ側で消えます。

| 原因 | 対処 |
| --- | --- |
| **URL（オリジン）が変わった** | Netlify Drop に**もう一度ドロップすると新しいサイト（別URL）が作られます**。保存先はURLごとなので、URLが変わると空に見えます。更新は必ず**既存サイトの Deploys にドラッグ**してください |
| **iPhone / iPad の Safari** | Safariは、7日間そのサイトを使わないとスクリプトが保存したデータを削除します。**ホーム画面に追加**して、そのアイコンから起動すると対象外になります |
| 履歴・サイトデータの削除 | 「Webサイトデータを消去」等で消えます |
| プライベートブラウズ | 閉じると消えます |
| 別の端末・別のブラウザで開いた | 保存は端末・ブラウザごとです |

**どの場合も「バックアップ」で復元できます。** 「きろく」画面の「**バックアップ（こえと きろく）**」で「ファイルに ほぞん」を押すと、声と記録をまとめた `sansu-note-backup-YYYY-MM-DD.json` が保存されます。消えたときは「ファイルから もどす」でそのファイルを選ぶだけです（**別の端末に声を移す**のにも使えます。同じファイルを2回読み込んでも記録は重複しません。サーバーのあいことばは、ファイルに秘密を残さないため含めていません）。

録音したら一度バックアップを取っておくことをおすすめします。

#### 録音できないとき

マイクが使えない理由は画面に出ます。理由ごとに対処が違います。

| 画面のメッセージ | 意味と対処 |
| --- | --- |
| この ページは ほかの ページの わくの 中で… | Artifactのプレビューなど**枠の中（iframe）**では、ページ側の設定でマイクが使えません。**新しいタブでページを開く**か、GitHub Pages・Netlifyで開いてください |
| この ひらきかた（ファイルを そのまま ひらく）では… | `index.html` を直接開いています。**https のページ**、または `http://localhost` で開いてください |
| マイクが きょか されて いません | ブラウザの**アドレスバーのマイクのマーク**から「許可」にして、もう一度押してください |
| マイクが みつかりません | マイクのある端末で開いてください |
| マイクが ほかの アプリで つかわれて います | 通話アプリなどを閉じてから押してください |

**録音済みの声を鳴らすことは、どの開きかたでもできます**（マイクが必要なのは録音のときだけです）。

### アニメごえ

端末の読み上げ（TTS）は**音色を変えられない**（ピッチの上限は2.0）ので、キャラクターらしい声は **WebAudio で合成**しています。文字数ぶんの短い音を、ビブラートと「口の形」に相当するフィルターを通して並べる方式です（ゲームやアニメのキャラクターボイスと同じ考え方）。

- 正解は音が**上がり**、まちがいは**下がる**ので、聞くだけでどちらか分かります
- ケロちゃんは 700Hz・やわらかい音、コロちゃんは 900Hz・はっきりした音
- **端末に日本語の音声が入っていなくても鳴ります**（Windows のPCなど）

「きろく」画面の「**ケロと コロの こえ**」で切り替えられます。

| こえの タイプ | ないよう |
| --- | --- |
| **アニメごえ＋ことば**（既定） | 短いアニメごえ → 名前を呼んでことばも読み上げ、の順。答えも読みます |
| **アニメごえ だけ** | アニメごえだけ（ことばは画面に出ます）。読み上げの声が苦手なときに |

「ことばの こえ」は端末にある声から選べます（「おまかせ」なら**女性・子どもに近い声を優先**し、男性の声は避けます。2種類以上あれば2匹で別々の声に）。「ケロで ためす」「コロで ためす」でその場で聞き比べられます。

しくみは**端末に入っている日本語の音声読み上げ**（Web Speech API）です。音声ファイルは同梱しておらず、通信も不要です。

| 端末 | 声 |
| --- | --- |
| iPhone / iPad / Mac | 最初から日本語の声が入っています（Kyoko など） |
| Android | 日本語の音声サービスが入っていれば使えます |
| Windows / PC のブラウザ | 日本語の音声が入っていないことがあります。その場合は**アニメごえだけ**で知らせます（ことばは画面に出ます） |

声を止めたいときは「こえ オフ」を押してください。

## 変更したときの確認

```bash
node tests/verify-questions.mjs   # 840問（さんすう360・えいご480）を自動で解いて照合
node tests/verify-kanji.mjs       # 漢字の画数・読み・4択、なぞりがき（書き順・向き・画数）の判定を照合
node tests/verify-typing.mjs      # タイピングの出題・指の割り当て・点数を照合
node tests/verify-sync.mjs        # 3台の端末で記録が1つにまとまるか（サーバーを立てて）
node tests/verify-api.mjs         # きろくサーバーのAPIを検証
node tests/verify-voice-order.mjs # ケロとコロの声が重ならないかを実時間で計測
```

`verify-kanji.mjs` のなぞりがきは、テストがお手本の線を実際にたどって**正しくなぞる／わざと間違える**の9通りを引き、通る・通らないで照合します（手ぶれつき・点4つだけ・書き順さかさま・1画ずつ逆向き・最後の1画を書かない・1画よけい・ぬりつぶし・落書き・何も書かない）。

`verify-questions.mjs` は答えを画面から独立に求めて照合します（筆算は問題文から、時計は針の角度から）。えいごは、選択肢が4つで重複がないこと・○の付いたボタンと答え合わせの答えが一致すること・テスト側が持っている単語表（アプリのデータとは別）と合うことを確かめます。出題や採点を変えたら実行してください。

## デザイン

「学習ノート」を素材にしています。方眼紙の背景、朱色の先生のペン、正解のときに**ペンで引かれる花まる**、
筆算のマス。装飾はこの文房具の世界にあるものだけで、それ以外は足していません。

- トップは、その子の名前と実際の連続日数で挨拶が変わります（決まり文句ではありません）
- さんすうは朱、えいごはみどり、かんじは紫、タイピングは藍。見出し・レベルの選択・すすむボタン・もくじの印まで、その画面はその色で通します
- 動きは正解の花まる1つだけ。`prefers-reduced-motion` では止まります
- 浮いて見えるのは「いま解いているページ」だけ。設定や結果の紙は影ではなく罫のふちで区切ります
- 文字の大きさは6段階、かどの丸みは3段階のトークンに揃えています（`CLAUDE.md` に一覧）

## つくり

- 依存ライブラリなし。HTML + CSS + バニラJSの1ファイル構成（アイコン・マニフェスト・`config.js`・`server/` を除く）。4つのアプリは同じ `index.html` の中にあり、画面・キャラクター・声・記録のしくみを共有しています。さんすう・えいご・かんじは出題エンジンまで同じで、タイピングだけゲームの回り方が違うため別建てです。
- サーバーのURLとあいことばは、アプリの画面から入れるか `config.js` に書けます。API本体（`server/api.mjs`）は Cloudflare Workers 版とローカル版で共通です。
- `manifest.webmanifest` とアイコンを同梱し、「ホーム画面に追加」で全画面のアプリとして起動します。
- キャラクターと花まる、時計はすべて SVG をコードで生成（画像ファイルなし）。
- 時計は学習用時計を SVG で生成（外側の輪に「分」の数字、短針＝朱色、長針＝藍色）。
- 書体は Google Fonts（Kiwi Maru / Zen Kaku Gothic New / M PLUS Rounded 1c）。読み込めない環境でも端末の書体で崩れずに表示されます。
- 文章は**わかち書き**にし、`word-break: keep-all` で語の途中（「ケロちゃ／んは」など）で行が折り返さないようにしています。
- 棒グラフの2色は同梱の検証スクリプト（dataviz skill の `validate_palette.js`）で、色覚特性・コントラストを確認して選んでいます（ライト `#e4523f`／`#2b6ca3`、ダーク `#e8603f`／`#3f8fd0`）。
- ライトテーマ／ダークテーマの両方に対応。スマートフォン幅（〜400px）でも横スクロールしません。
