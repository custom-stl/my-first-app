# キッズタイマー（Windows）

子どもが Windows に**ログインした時点からカウントを始め**、決めた時間（**5分きざみ・最大60分**）で
サインアウトさせるタイマーです。**時間の設定は親（管理者）しかできません。**

## しくみ

- ログインすると、画面の右下に「のこり じかん」が出ます（× では閉じられません。ドラッグで移動できます）
- のこり **5分** と **1分** でお知らせが出ます
- 0分になると「じかんに なったよ」の全画面になり、**60秒後**にサインアウトします
  （設定で「画面をロック」「シャットダウン」も選べます）
- 設定は `C:\ProgramData\KidsTimer\config.json` にあり、**管理者しか書き換えられません**。
  子どもが「おやの せってい」を押すと Windows が管理者のパスワードを聞くので、親がその場で入力して変更できます

## 準備

1. **子どものアカウントを「標準ユーザー」にする**（設定 → アカウント → 家族とその他のユーザー → アカウントの種類の変更）。
   子どもが管理者だと UAC で「はい」を押すだけで設定を変えられてしまいます
2. 親の管理者アカウントでログインし、この ZIP を解凍する
3. `Install.cmd` をダブルクリック（「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」）
4. 開いた設定画面で、子どものアカウントの「じかん」を選んで「ほぞん」
5. 子どものアカウントでログインすると、タイマーが始まります

## 設定画面

スタートメニューの **「キッズタイマー せってい」**、またはタイマーの「おやの せってい」から開きます。

| 項目 | 内容 |
| --- | --- |
| じかん | せいげん なし／5〜60分（5分きざみ） |
| きょうだけ ふやす | その日だけ +5〜+60分。翌日は元に戻る。ログイン中でも数秒で反映 |
| きろくを 0 に | その日に使った時間をリセット |
| かぞえかた | **1日の合計**（ログインし直しても続きから。既定）／ログインのたびに はじめから |
| じかんに なったら | サインアウト（既定）／画面をロック／シャットダウン |

## アンインストール

親の管理者アカウントで `Uninstall.cmd` をダブルクリック。

## 知っておいてほしいこと

- スリープ中は数えません
- 「1日の合計」は日付が変わると 0 に戻ります
- 使った時間の記録（`C:\ProgramData\KidsTimer\usage`）はタイマーが書き込むため、子どもの権限でも書けます。
  パソコンに詳しい子なら、タスクマネージャーでタイマーを止めたり記録を消したりできてしまいます。
  より厳密に管理したい場合は Windows 標準の「Microsoft ファミリー セーフティ」のスクリーンタイム制限との併用をおすすめします
- 動作環境：Windows 10 / 11（Windows PowerShell 5.1。追加インストール不要）
